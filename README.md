### engineering philosophy

- *no magic:* If I didn't write it or don't understand how it maps to machine code, it doesn't belong in my binary.
- *zero allocation where possible:* Garbage collection is a luxury, not a default.
- *privacy first:* Secure by default, offline-first, decentralized.
